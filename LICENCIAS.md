## Cómo atribuir el código y la documentación

- En un fork, conserva el texto de `LICENSE` y el aviso de copyright del código MIT original. Puedes reemplazar el diseño, los textos y el catálogo por los tuyos.
- Si compartes una **guía técnica original** o una adaptación de ella, atribuye «Afaces / Axel Fernández Curros», enlaza a su fuente y a CC BY-SA 4.0, identifica tus cambios y publica la guía derivada bajo CC BY-SA 4.0.
- Los contenidos artísticos no viajan con el permiso de uso del código. Sustituye el nombre, los MP3, las fotografías, las portadas y las rutas de Afaces antes de publicar tu web.
- La radio original de Afaces usa un **repositorio de música distinto** y puede depender de Git LFS. Tener el reproductor no implica tener licencia para redistribuir los MP3.
- El código de terceros integrado o enlazado (por ejemplo, Bootstrap o Bootswatch en la web histórica) conserva sus condiciones y atribuciones originales. La licencia MIT de Afaces solo se aplica a las partes sobre las que puede conceder derechos.
- Si algún fichero mezcla lógica con contenido creativo, MIT cubre la **lógica y estructura original del software**, **no** los elementos artísticos incrustados.
